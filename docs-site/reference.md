# Referencia pública

Este índice reúne las claves de configuración, variables de entorno, helpers globales, entradas CLI, contratos y familias de clases que aparecen en el checkout del 2026-10-24. Las referencias describen código y configuración fuente; no prueban que una dependencia Composer se haya instalado en una aplicación consumidora ni que un proveedor externo o una base de datos responda.

## Carga y disponibilidad

El manifiesto raíz declara el prefijo PSR-4 `Boctulus\Simplerest\Core\` hacia `src/framework/`. Composer excluye `src/framework/Templates/` del classmap. En el bootstrap de la aplicación, [`app.php`](https://github.com/boctulus/simplerest/blob/efa2bc11c53b3f2d9d940b45326ffb0df117dce1/app.php) carga Composer y después incluye los directorios `src/framework/Helpers/` y `app/Helpers/` listados por [`config/autoload.php`](https://github.com/boctulus/simplerest/blob/efa2bc11c53b3f2d9d940b45326ffb0df117dce1/config/autoload.php). Por eso los helpers del core pertenecen al bootstrap de aplicación existente; el autoload PSR-4 de Composer, por sí solo, no carga esas funciones.

El manifiesto que declara ese prefijo es [`composer.json`](https://github.com/boctulus/simplerest/blob/efa2bc11c53b3f2d9d940b45326ffb0df117dce1/composer.json).

Los helpers `psr7_*()` y `setLang()`/`trans()` pertenecen a paquetes opcionales cuyos manifiestos declaran `autoload.files`. Sólo están disponibles cuando Composer carga el paquete correspondiente. Algunas funciones del core también están condicionadas por `function_exists()` o actúan como polyfill. Véanse los [adaptadores PSR-7](https://github.com/boctulus/simplerest/blob/efa2bc11c53b3f2d9d940b45326ffb0df117dce1/docs/packages/http-adapters.md), [localización](https://github.com/boctulus/simplerest/blob/efa2bc11c53b3f2d9d940b45326ffb0df117dce1/docs/packages/localization.md) y [configuración y entorno](/core/configuration-environment).

## Claves de configuración

La fuente de las claves del runtime es [`config/config.php`](https://github.com/boctulus/simplerest/blob/efa2bc11c53b3f2d9d940b45326ffb0df117dce1/config/config.php). Esta tabla conserva los nombres exactos, incluidos los que contienen errores ortográficos históricos.

| Área | Claves | Valor por defecto o condición visible en el código |
| --- | --- | --- |
| Identidad | `app_url`, `app_name`, `app_env`, `namespace`, `base_url` | Las tres primeras se leen del entorno sin fallback explícito; namespace `Boctulus\Simplerest`; `base_url` vacío. |
| Entrada y routing | `web_router`, `console_router`, `front_controller`, `front_behaviors`, `remove_api_slug`, `default_controller`, `template` | Routers y front controller habilitados; seis handlers predeterminados; conserva `/api`; controlador `HomeController`; plantilla `templates/tpl.php`. |
| HTTP y proceso | `https`, `ssl_cert`, `DateTimeZone`, `tmp_dir`, `method_override` | HTTPS y certificado `null` por defecto; el comentario de fuente indica que `ssl_cert = false` desactiva verificación; zona `Asia/Manila`; temporal del sistema; override por URL y header habilitado. |
| Errores y trazas | `error_handling`, `debug`, `error_log`, `log_file`, `log_sql`, `log_errors`, `log_stack_trace`, `var_dump_separators` | Manejo de errores y SQL debug desactivados; `APP_DEBUG` y `LOG_SQL` usan `false` como fallback; error log y log de errores habilitados; `log.txt`; stack trace desactivado; separadores configurables. |
| API y datos | `users_table`, `include_enity_name`, `nest_sub_resources`, `paginator`, `pretty`, `restrict_by_ip`, `restrict_by_user_agent`, `restrict_by_tenant`, `acl_file` | Tabla `users`; las dos opciones de representación y los tres límites de acceso están desactivados; paginador con máximo 50, default 10, parámetros `size` y `page`; ACL cache bajo `SECURITY_PATH`. El código escribe `include_enity_name` así. |
| Tokens y roles | `access_token`, `refresh_token`, `email_token`, `auto_approval_roles`, `default_role`, `pre_activated` | Secretos leídos del entorno, expiraciones de 3600, 1209600 y 3600 segundos, algoritmo HS256; roles `admin`, `usuario`, `supervisor`, `superadmin`; rol default `null`; usuarios preactivados. No se muestran valores de secretos. |
| Correo | `email` | Remitente y datos SMTP se leen del entorno; mailer default `google`. |
| Servicios | `sleep_time`, `translate`, `providers`, `cache_driver`, `use_composer` | Pausa API Client de `0.15`; gettext desactivado; `DBCache`; Composer habilitado. El array `providers` de esta aplicación contiene FineGrained ACL, LLM Providers y el módulo Security; son selecciones de este checkout, no defaults universales. |
| Integraciones | `openai_api_key`, `claude_api_key`, `google_console_api_key`, `google_maps_api_key`, `sendinblue_api_key`, `google_auth`, `facebook_auth` | Credenciales y callbacks se leen del entorno, sin valores secretos en esta referencia. |

[`config/databases.php`](https://github.com/boctulus/simplerest/blob/efa2bc11c53b3f2d9d940b45326ffb0df117dce1/config/databases.php) define estas claves:

| Clave | Alcance observado |
| --- | --- |
| `db_connections` | Perfiles declarados: `main`, `relmotor`, `laravelshopify`, `edu`, `az`, `test_sqlite` y `pg_test`. Algunos perfiles adicionales están comentados y no forman parte del array activo. Los campos de conexión incluyen `host`, `port`, `driver`, `db_name`, `user`, `pass`, `charset`, `schema`, `engine`, `pdo_options` y `tb_prefix`, según el perfil. |
| `db_connection_default` | Identificador default `main`. |
| `tentant_groups` | Nombre literal de la clave en este checkout; conserva la grafía histórica `tentant`. |

[`config/commands.php`](https://github.com/boctulus/simplerest/blob/efa2bc11c53b3f2d9d940b45326ffb0df117dce1/config/commands.php) define `paths`, `packages`, `framework_paths`, `overrides` y `cross_aliases`. Actualmente habilita el paquete `boctulus/simplerest-scaffolding` y declara el alias cruzado `make acl` → `acl make`. El catálogo CLI completo y los efectos por comando están en [php com](/cli/commands).

## Variables de entorno

Los nombres siguientes se extraen de las lecturas activas en `config/`, `src/framework/`, `app/` y `packages/boctulus/`. Un nombre presente en el código no implica que esté definido en este equipo. No se incluyen valores de credenciales.

| Uso | Variables referenciadas | Condición o fallback fuente |
| --- | --- | --- |
| Identidad y diagnóstico | `APP_URL`, `APP_NAME`, `APP_ENV`, `APP_DEBUG`, `LOG_SQL` | `APP_DEBUG` y `LOG_SQL` usan fallback `false`; el resto se lee sin fallback explícito. `APP_ENV` también participa en la condición de seguridad TLS del adaptador Google Drive. |
| Base de datos | `DB_HOST`, `DB_PORT`, `DB_CONNECTION`, `DB_NAME`, `DB_USERNAME`, `DB_PASSWORD`; los grupos equivalentes `DB_HOST_RELMOTOR`, `DB_PORT_RELMOTOR`, `DB_CONNECTION_RELMOTOR`, `DB_NAME_RELMOTOR`, `DB_USERNAME_RELMOTOR`, `DB_PASSWORD_RELMOTOR`, `DB_CHARSET_RELMOTOR`; y `DB_HOST_EDU`, `DB_PORT_EDU`, `DB_CONNECTION_EDU`, `DB_NAME_EDU`, `DB_USERNAME_EDU`, `DB_PASSWORD_EDU` | `DB_HOST`, `DB_HOST_RELMOTOR` y `DB_HOST_EDU` tienen fallback `127.0.0.1`; `DB_CHARSET_RELMOTOR` tiene fallback `utf8`. Los perfiles `laravelshopify` y `az` reutilizan las seis variables sin sufijo. |
| Tokens | `TOKENS_ACCSS_SECRET_KEY`, `TOKENS_REFSH_SECRET_KEY`, `TOKENS_EMAIL_SECRET_KEY` | Nombres exactos del código; `ACCSS` y `REFSH` conservan errores ortográficos. No se imprime ningún secreto. |
| Correo | `MAIL_DEFAULT_FROM_ADDR`, `MAIL_DEFAULT_FROM_NAME`, `MAIL_HOST`, `MAIL_PORT`, `MAIL_USERNAME`, `MAIL_PASSWORD`, `MAIL_ENCRYPTION`, `MAIL_AUTH` | Consumidas por la configuración SMTP del core; el envío real corresponde al paquete opcional de correo. |
| OAuth y servicios del core | `OPENAI_API_KEY`, `CLAUDE_API_KEY`, `GOOGLE_CONSOLE_API_KEY`, `GOOGLE_MAPS_API_KEY`, `SENDINBLUE_API_KEY`, `OAUTH_GOOGLE_CLIENT_ID`, `OAUTH_GOOGLE_CLIENT_SECRET`, `OAUTH_GOOGLE_CALLBACK`, `OAUTH_FACEBOOK_CLIENT_ID`, `OAUTH_FACEBOOK_CLIENT_SECRET`, `OAUTH_FACEBOOK_CALLBACK` | Configuración fuente del core; que exista una clave no demuestra una llamada autenticada. |
| Paquetes opcionales | `LLM_DEFAULT_PROVIDER`, `XAI_API_KEY`, `DEGUG` | `LLM_DEFAULT_PROVIDER` usa `openai` como fallback. `DEGUG` está mal escrito en el código y Google Drive lo consulta como una de varias condiciones para desactivar validación TLS; véase [API Clients](/integrations/api-clients). |
| Aplicación de ejemplo y herramientas | `AMELIA_API_URL`, `AMELIA_API_KEY`, `SENDGRID_API_KEY`, `EXCHANGERATE_API_KEY`, `ROBOT_PATH`, `PYTHON_BINARY`, `PHP_BINARY`, `PATH`, `HOME`, `USERPROFILE` | Usadas por controladores, ejemplos, utilidades de sistema o comandos de la aplicación anfitriona; no son configuración general del core. |

`DB_*_WOO3`, `DB_*_PARTS`, `DB_*_2`, `DB_*_MPO_DOCKER`, `DB_*_MPP` y `DB_*_REMOTE` aparecen en bloques comentados; esta referencia no los clasifica como perfiles activos. El paquete i18n escribe `LANG`, `LANGUAGE` y `LC_ALL` al seleccionar el locale: en ese flujo son efectos de proceso y no entradas de configuración de SimpleRest.

## Entradas de comandos

La entrada `php com` construye el catálogo `CommandRegistry` desde `app/Commands/`, las rutas configuradas y los paquetes habilitados; la configuración vigente habilita scaffolding. Formas de ayuda que sólo consultan el catálogo:

```text
php com help
php com help <grupo>
php com <grupo> help
```

En la ayuda global observada en este checkout aparecen los grupos `acl`, `doc`, `file`, `make`, `migrations`, `module`, `mysql`, `pack`, `roles`, `router`, `skill`, `sql`, `system`, `todo` y `users`. El catálogo puede cambiar con la aplicación, rutas y paquetes habilitados. Consulta la [referencia CLI](/cli/commands) para comandos y límites de efectos.

`CliRouter` es otra entrada: registra rutas CLI de aplicación y su resolución es independiente del grupo `php com`. Cuando CommandRegistry no reconoce un grupo, `com` puede continuar por CliRouter y luego por FrontController según la configuración; `pack` tiene una rama especial. Esta auditoría consultó pantallas de ayuda y no ejecutó subcomandos operativos ni rutas de CliRouter.

Fuentes de dispatch: [`com`](https://github.com/boctulus/simplerest/blob/efa2bc11c53b3f2d9d940b45326ffb0df117dce1/com), [`CommandRegistry.php`](https://github.com/boctulus/simplerest/blob/efa2bc11c53b3f2d9d940b45326ffb0df117dce1/src/framework/Libs/CommandRegistry.php), [`BaseCommand.php`](https://github.com/boctulus/simplerest/blob/efa2bc11c53b3f2d9d940b45326ffb0df117dce1/src/framework/Commands/BaseCommand.php), [`CliRouter.php`](https://github.com/boctulus/simplerest/blob/efa2bc11c53b3f2d9d940b45326ffb0df117dce1/src/framework/CliRouter.php), [`FrontController.php`](https://github.com/boctulus/simplerest/blob/efa2bc11c53b3f2d9d940b45326ffb0df117dce1/src/framework/FrontController.php) y [`config/commands.php`](https://github.com/boctulus/simplerest/blob/efa2bc11c53b3f2d9d940b45326ffb0df117dce1/config/commands.php).
