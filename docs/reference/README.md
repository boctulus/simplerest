# Referencia pública

Este índice reúne las claves de configuración, variables de entorno, helpers globales, entradas CLI, contratos y familias de clases que aparecen en el checkout del 2026-10-24. Las referencias describen código y configuración fuente; no prueban que una dependencia Composer se haya instalado en una aplicación consumidora ni que un proveedor externo o una base de datos responda.

## Carga y disponibilidad

El manifiesto raíz declara el prefijo PSR-4 `Boctulus\Simplerest\Core\` hacia `src/framework/`. Composer excluye `src/framework/Templates/` del classmap. En el bootstrap de la aplicación, [`app.php`](../../app.php) carga Composer y después incluye los directorios `src/framework/Helpers/` y `app/Helpers/` listados por [`config/autoload.php`](../../config/autoload.php). Por eso los helpers del core pertenecen al bootstrap de aplicación existente; el autoload PSR-4 de Composer, por sí solo, no carga esas funciones.

El manifiesto que declara ese prefijo es [`composer.json`](../../composer.json).

Los helpers `psr7_*()` y `setLang()`/`trans()` pertenecen a paquetes opcionales cuyos manifiestos declaran `autoload.files`. Sólo están disponibles cuando Composer carga el paquete correspondiente. Algunas funciones del core también están condicionadas por `function_exists()` o actúan como polyfill. Véanse los [adaptadores PSR-7](../packages/http-adapters.md), [localización](../packages/localization.md) y [configuración y entorno](../core/configuration-environment.md).

## Entradas de comandos

La entrada `php com` construye el catálogo `CommandRegistry` desde `app/Commands/`, las rutas configuradas y los paquetes habilitados; la configuración vigente habilita scaffolding. Formas de ayuda que sólo consultan el catálogo:

```text
php com help
php com help <grupo>
php com <grupo> help
```

En la ayuda global observada en este checkout aparecen los grupos `acl`, `doc`, `file`, `make`, `migrations`, `module`, `mysql`, `pack`, `roles`, `router`, `skill`, `sql`, `system`, `todo` y `users`. El catálogo puede cambiar con la aplicación, rutas y paquetes habilitados. Consulta la [referencia CLI](../cli/commands.md) para comandos y límites de efectos.

`CliRouter` es otra entrada: registra rutas CLI de aplicación y su resolución es independiente del grupo `php com`. Cuando CommandRegistry no reconoce un grupo, `com` puede continuar por CliRouter y luego por FrontController según la configuración; `pack` tiene una rama especial. Esta auditoría consultó pantallas de ayuda y no ejecutó subcomandos operativos ni rutas de CliRouter.

Fuentes de dispatch: [`com`](../../com), [`CommandRegistry.php`](../../src/framework/Libs/CommandRegistry.php), [`BaseCommand.php`](../../src/framework/Commands/BaseCommand.php), [`CliRouter.php`](../../src/framework/CliRouter.php), [`FrontController.php`](../../src/framework/FrontController.php) y [`config/commands.php`](../../config/commands.php).
