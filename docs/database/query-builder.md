# Query Builder

This page covers a narrow, source-traced query path. No database query or PHPUnit case was run for this audit, so the examples and signatures below are not a reproduced application workflow.

## Entry point

[`DB::table($from, $alias = null, $connect = true)`](../../src/framework/Libs/DB.php#L625) has two paths. For a table name it resolves an application model with `get_model_name()` and constructs that model. If `$from` contains ` FROM `, it instead constructs `MyModel` and calls `fromRaw()`.

The default `$connect` value is `true`. The [base `Model`](../../src/framework/Model.php#L14) uses [`QueryBuilderTrait`](../../src/framework/Traits/QueryBuilderTrait.php#L21); its constructor calls `connect()` when requested, which selects the current PDO connection. A table name therefore depends on the app's model/schema mapping and configured database connection.

## Building and executing a read

The source-level call shapes below are implemented by [`select()`](../../src/framework/Traits/QueryBuilderTrait.php#L920) and [`where()`](../../src/framework/Traits/QueryBuilderTrait.php#L2624):

- `select('id', 'name')`, `select(['id', 'name'])`, and a comma-separated string are normalized into a field list.
- `where('id', 7)` and `where('id', '>', 2)` are converted to conditions. The method also accepts its array condition form.
- [`toSql()`](../../src/framework/Traits/QueryBuilderTrait.php#L1116) builds the SQL and records the precompiled SQL and bindings. It does not execute the query.
- On the ordinary, non-connected-table read path, [`get()`](../../src/framework/Traits/QueryBuilderTrait.php#L1852) builds SQL, prepares a PDO statement, binds values, and executes it when the model's `$exec` flag is true. On an executed read it returns fetched rows; with execution disabled it returns `false`.

[`dontExec()`](../../src/framework/Traits/QueryBuilderTrait.php#L392) disables statement preparation/execution in the builder path, but it does not make the standard `DB::table(...)->get()` flow offline. `DB::table()` connects by default, and `get()` reaches `bind()`, which connects if the model has no PDO handle before it checks `$exec`.

When the model schema contains `deleted_at`, query construction adds `deleted_at IS NULL` unless deleted rows have been enabled with `deleted()`. The condition is generated by [`whereFormedQuery()`](../../src/framework/Traits/QueryBuilderTrait.php#L1414); its scope depends on the active model schema.

## Observed result edge case

On the executed path, [`first()`](../../src/framework/Traits/QueryBuilderTrait.php#L1903) fetches one row. When the fetch is empty, the current source returns `[]`, not `null`. This behavior has not been exercised against a live database and is recorded as an implementation inconsistency.

## Write-mode safety finding

`preview()` and `simulate()` are not a universal no-write guarantee. The source has mode checks in `create()` and `executeInsert()`, but `update()` and `delete()` execute when `$exec` is true without checking the selected execution mode. The legacy `preview()->update(...)` example is therefore rejected as unsafe. This anomaly is recorded for separate implementation investigation; no framework code was changed.

## Evidence and scope

`ModelTest::test_get()` and `QueryBuilderExtendedTest::test_soft_deletes()` contain SQL assertions for selected query forms; the tests were inspected, not executed. These tests load the application, and normal `DB::table()` construction opens the configured connection. The configured [PHPUnit file](../../phpunit.xml) does not include `unit-tests/`, so these assertions are not evidence of the repository's default `composer test` run.

Write operations, transaction behavior, execution-mode safety, raw-query contracts, pagination, aggregates, relation loading, automatic joins, and PostgreSQL compatibility remain outside this page's verified scope. See the [claim-level audit](../audit/README.md#claim-level-findings-query-builder), [connection behavior](connections.md), and [quarantined Query Builder guide](../audit/pending/framework/QueryBuilder.md).
